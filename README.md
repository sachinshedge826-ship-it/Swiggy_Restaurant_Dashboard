##Swiggy Restaurant Data Analysis and Interactive Dashboard using Microsoft Excel##
Project Objective
The main objective of this project is to analyze Swiggy restaurant data using Microsoft Excel and develop an interactive dashboard to generate meaningful business insights.

The project aims to:
1. Analyze average restaurant ratings across different cities.
2. Identify areas with the highest number of restaurants.
3. Understand the most common food type combinations.
4. Identify top 5 restaurants based on total customer ratings.
5. Compare average delivery times across different cities.
6. Help businesses make data-driven decisions using interactive visualizations and KPIs.
Short Objective (for Resume):

"To analyze Swiggy restaurant data using Microsoft Excel and create an interactive dashboard that provides insights into restaurant performance, customer ratings, food preferences, restaurant distribution, and delivery time."
